# ジャケットを中心にしたプレーヤーUI

ユーザーが提示したSpotifyの画面を参考に、ToneKeepのネイティブUIを更新した。

## 表示と操作

- ライブラリは黒背景、白い曲名、控えめなアーティスト名、56dpのジャケット、右端の操作メニューを持つ一覧。曲の行をタップして再生する。処理中・失敗・待機は行内に表示し、中止・再試行も引き続き操作できる。
- 下部にジャケット・曲名・アーティスト・再生/停止・終了・再生進捗のミニプレーヤーを配置。ミニプレーヤーをタップすると全画面表示を開く。
- 全画面は大きな正方形ジャケット、画像から抽出した色のグラデーション、曲名、アーティスト、シーク、再生時刻、前/次、シャッフル、全曲/1曲リピート、音源共有を表示する。緑のチェックは「端末に保存済み」を示す。
- 歌詞カードから歌詞を拡大できる。ミニ・全画面・拡大歌詞は同じMediaPlayerの再生位置を使い、歌詞行タップのシークも共有する。
- メニューから従来のAI歌詞生成、歌詞検索・取り込み、なぞり/AI同期、書き出し、キー変更、詳細を開ける。曲情報の取得元、音質、処理状況は詳細に残す。
- 再生順は保存済みファイルIDで保持し、同名曲・キー変更版を分離する。シャッフルでは現在の曲を維持して残りを並べ替える。曲の先頭から3秒を過ぎた「前」は先頭へ戻り、それ以前は前の曲へ移る。
- キー変更の試聴・直接読み込みには、保存済み曲キューを誤って使わない。試聴のシャッフル・リピートは無効にする。
- 画面回転後は保存済み曲のID・再生位置・拡大表示・シャッフル/リピート設定を維持する。再生サービス導入後は再生中の音も継続する（[今回の変更](playback-notification.md)）。

## 画像と通信

一覧と全画面で適切な解像度を使い、画像は容量制限付きのキャッシュから非同期で読み込む。再生画面を開くだけでは通信しない。
曲情報を取得・更新するときに大きいジャケットを保存する。[Cover Art Archive API](https://musicbrainz.org/doc/Cover_Art_Archive/API)の1200pxを優先し、取得できない場合は500pxへフォールバックする。既存の画像は取得し直すまで以前の画質のまま使える。

## 変更ファイル

`MainActivity.java`、`AudioPlayer.java`、`ArtworkLoader.java`、`MusicCatalog.java`、`UiIcon.java`、`res/values/styles.xml`を更新。
再生順の小さな状態クラス`PlaybackOrder.java`を追加。音声処理、歌詞解析モデル、SQLiteのスキーマは今回変更していない。

`PlaybackOrderTest`は前後移動・反復・シャッフル・ID分離を確認する。
`PlayerUiTest`は自作音声と自作画像で、実際のAPKの再生・停止・曲切り替え・歌詞シーク・全画面切り替え・画面再作成を確認する。
`LyricsSyncModesTest`でなぞり方式・AI照合方式、`NativePitchTest`で既存のキー変更と再生を確認する。
画像更新だけを行う任意の`OnlineSongInfoTest#refreshOnlyTheRetainedDemoArtworkForTheLargePlayer`は、現在の歌詞を変更しないことも検査する。

## 検証結果と残る確認

- 単体テスト70件成功。Android lintはエラー0・警告19件。3 ABIを含む検証用APKとテストAPKのGradleビルド成功。
- SC-51G / Android 17で`PlayerUiTest`2件と`LyricsSyncModesTest`3件、計5件が成功。再生・停止、曲切り替え、シャッフル/リピートの切り替え、歌詞行からのシーク、拡大表示、画面再作成後の一時停止復元、行/単語なぞり、AI照合の既存動作を確認した。
- 実曲SAYONARA MAYBEで、新しい一覧・ミニプレーヤー・赤いジャケットに合わせた全画面表示を確認した。
- その後の1200px画像取得、画像サンプリングと一覧余白の調整、閉じたプレーヤーを回転時に復元しない修正は、Gradleビルド・単体テスト・lintで確認した。ADB接続が切れ、ユーザー指定でAPK作成までとしたため、これら最後の差分を端末へ再インストールした確認と、今回の改修後の`NativePitchTest`再実行は未実施。
- サーバーからの高解像度画像取得は今回の実機では未確認。既存の画像はそのまま表示できる。新UIによって歌詞認識・同期の精度は変わらない。
- 最終APKは`dist/ToneKeep-player-ui-preview.apk`。applicationIdは既存の検証用`jp.tonekeep.app.offlineverify`。通常版や別IDのToneKeepを上書きしない。GitHubへの公開は行っていない。
